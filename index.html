انتخاب فایل اکسل
📌 این ابزار چه کاری انجام می‌دهد؟
برای هر کامنت اینستاگرام یک لینک مستقیم می‌سازد که با کلیک روی آن، دقیقاً همان نظر در اینستاگرام باز می‌شود.

📋 مراحل استفاده:
۱. فایل اکسل خود را آپلود کنید — فایل باید حاوی ستونی با Comment ID (شناسه یکتای کامنت) باشد.
۲. ستونی که Comment ID در آن قرار دارد را انتخاب کنید.
۳. لینک پست اینستاگرام را وارد کنید.
    مثال: https://www.instagram.com/p/DWHC8pbB5EG/
۴. سیستم به‌صورت خودکار Shortcode پست را از لینک استخراج می‌کند.
۵. دکمه «ساخت لینک‌ها» را بزنید تا یک فایل اکسل جدید دانلود شود.

🔗 فرمت لینک خروجی:
https://www.instagram.com/p/[SHORTCODE]/c/[COMMENT_ID]/

⚠️ نکات مهم:
• Comment ID باید عدد باشد (مثلاً 18062540354392499).
• لینک پست باید از قسمت /p/ داشته باشد.
• اگر سلولی Comment ID معتبر نداشت، آن سلول خالی می‌ماند.
• تمام ستون‌های دیگر فایل اصلی بدون تغییر در خروجی حفظ می‌شوند و یک ستون جدید با عنوان Comment Link اضافه می‌شود.

🌍 تفکیک کشوری شماره تلفن

• فایل اکسل را آپلود کنید و ستون شماره تلفن را انتخاب کنید.
• شماره‌ها باید با کد کشور شروع شوند (با + یا بدون آن).
  مثال: +989123456789  یا  989123456789  یا  00989123456789
• سیستم بر اساس دیتابیس +۲۳۵ کشور شماره‌ها را تشخیص می‌دهد.
• یک فایل ZIP دریافت می‌کنید که هر کشور فایل جداگانه‌ای است.
• شماره‌های ناشناس در فایل نامشخص ذخیره می‌شوند.

⚠️ نکته: شماره‌های ایرانی که با 09 شروع می‌شوند باید ابتدا با تب «اصلاح شماره» به فرمت +98 تبدیل شوند.
